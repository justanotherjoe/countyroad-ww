CUSTOM CABINETRY GALLERY
========================

Drop photos for the "Custom Cabinetry" gallery in this folder.

Recommended:
  - JPG or PNG files
  - At least 1200px on the longest side for crisp display
  - Lower-case filenames with hyphens (e.g. kitchen-walnut-01.jpg)

After adding files, edit index.html and find the GALLERIES config
near the top of the <script> tag at the bottom of the file. Add
a line under "cabinetry" for each photo, like:

  { src: 'gallery/cabinetry/kitchen-walnut-01.jpg', caption: 'Walnut Kitchen' },

The order of items in the array is the order they show up in the carousel.
