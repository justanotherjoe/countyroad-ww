SPECIALTY & CUSTOM GALLERY
==========================

Drop photos for the "Specialty & Custom" gallery in this folder
(barn doors, mantels, live-edge slabs, one-of-a-kind pieces).

After adding files, edit index.html and find the GALLERIES config
in the <script> tag. Add a line under "specialty" for each photo:

  { src: 'gallery/specialty/barn-door-01.jpg', caption: 'Reclaimed Barn Door' },
